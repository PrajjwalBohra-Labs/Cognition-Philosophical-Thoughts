# 7. Source Navigation

```text

 ↓

 ↓
Identify Sanskrit term
 ↓
Locate primary text
 ↓
Read commentary
 ↓
Compare rival position
```

---

# 8. Search Strategy

Search in this order:

### Exact Sanskrit term

Example:

```text
vyāpti
samavāya
pramāṇa
śabda
```

### Concept

Example:

```text
inference
inherence
testimony
absence
```

### Argument

Example:

```text
argument for self
argument against perception
definition of vyāpti
```

### Text

Example:

```text
Tattvacintāmaṇi Anumāna
Nyāya Sūtra Śabda
Vākyapadīya Sphoṭa
```

---

# 9. Reference Discipline

Always distinguish:

```text
Text
Commentary
Interpretation
Comparison
Modern analogy
Personal hypothesis
```

Do not mix them into a single undifferentiated claim.

---

# 10. Maintenance

When adding a new book:

1. Add it to `bibliography.md`.
2. Add its author to `philosophers.md` if appropriate.
3. Add its school to `schools.md`.
4. Add relevant terminology to `terminology.md`.
5. Add it to `reading-order.md`.
6. Add historical information to `timeline.md` if appropriate.
7. Update this index if it creates a new research area.

---

# Core Principle

> **The reference directory should make the repository navigable without becoming a substitute for reading the books.**
