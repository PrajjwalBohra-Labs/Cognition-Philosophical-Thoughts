# Concepts

This file is a conceptual map of the major philosophical ideas represented in the repository.

It is not intended to replace the glossary. The glossary answers **"What does this term mean?"** This file answers **"How do the major concepts connect?"**

---

# 1. The Epistemological Network

```text
Prameya
   ↑
Pramā
   ↑
Pramāṇa
   ↑
Cognition
   ↑
Knowing conditions
```

### Pramāṇa

Means of valid cognition.

### Pramā

Valid cognition.

### Prameya

Object of valid cognition.

### Jñāna

Cognition / knowledge in context.

The basic epistemological problem is:

> How does a cognition become knowledge of an object?

---

# 2. Cognition Network

```text
Cognition
├── Perception
├── Inference
├── Comparison
├── Testimony
├── Memory
├── Doubt
└── Error
```

Important distinctions:

- *anubhava* — presentative cognition;
- *smṛti* — memory;
- *saṃśaya* — doubt;
- erroneous cognition.

Do not assume these categories have identical definitions across all schools.

# 9. Language Network

```text
Śabda
 │
 ├── Word
 ├── Meaning
 ├── Sentence
 ├── Verbal cognition
 ├── Authority
 └── Sphoṭa
```

Different traditions organize this network differently.

### Nyāya

Focuses on testimony, reliable speaker, word, sentence, and verbal cognition.

### Mīmāṃsā

Places major emphasis on Vedic authority, sentence meaning, interpretation, and *dharma*.

### Bhartṛhari

Develops a distinctive philosophy of *śabda*, sentence, meaning, and cognition.

without argument.

# 11. Causal and Soteriological Network

A major Nyāya-Vaiśeṣika pattern can be represented as:

```text
False cognition
 ↓
Faults
 ↓
Activity
 ↓
Dharma / Adharma
 ↓
Embodiment
 ↓
Experience
 ↓
Suffering
```

And the reverse movement:

```text
Correct knowledge
 ↓
Removal of false cognition
 ↓
Cessation of faults
 ↓
Cessation of bondage-producing activity
 ↓
Liberation
```

# 12. Cross-School Concept Map

| Problem | Nyāya | Vaiśeṣika | Mīmāṃsā | Bhartṛhari |
|---|---|---|---|---|
| Knowledge | Pramāṇa/pramā | Knowledge and categories | Multiple pramāṇas | Language/cognition |
| Inference | Central | Recognized | Distinct treatment | Not central |
| Testimony | Reliable speaker | Discussed | Major importance | Language-centered |
| Ontology | Realist analysis | Systematic categories | Different emphasis | Different framework |
| Language | Word/sentence | Sound and related issues | Vedic language | Śabda/sphoṭa |
| Self | Ātman | Ātman | Tradition-specific | Different framework |

This table is a starting map, not a substitute for textual study.

# 14. Modern Conceptual Bridges

Useful modern comparisons include:

```text
Pramāṇa → source of justified information
Anumāna → structured inference
Hetvābhāsa → reasoning defect
Śabda → testimony / information source
Smṛti → memory
Saṃśaya → uncertainty
Vyāpti → general inferential relation
Ontology → domain/world modeling
Relations → relational modeling
```

These are **functional analogies**, not identity statements.

---

# Core Principle

> **Concepts become philosophically useful when their dependencies and contrasts are understood, not when their definitions are memorized in isolation.**
