# Decision Theory

Decision theory studies how agents should choose actions when outcomes, probabilities, values, and uncertainty are involved.

It is useful for connecting philosophical reasoning with practical action.

---

# 1. Separate Truth From Choice

A crucial distinction:

```text
Epistemic question:
What is likely to be true?

Decision question:
What should I do given what I know?
```

These are related but not identical.

---

# 2. Basic Decision Model

Represent a decision as:

```text
Decision
├── Available actions
├── Possible states
├── Outcomes
├── Evidence
├── Probabilities / uncertainty
└── Values / costs
```

---

# 3. Evidence Before Action

Use:

```text
Situation
 ↓
Available evidence
 ↓
Epistemic assessment
 ↓
Possible outcomes
 ↓
Action
 ↓
Result
 ↓
Revision
```

This separates reasoning from impulse.

---

# 4. Uncertainty

Not knowing does not necessarily mean refusing to act.

Distinguish:

- known;
- unknown;
- uncertain;
- estimated;
- assumed.

Record assumptions explicitly.

---

# 5. Expected Value

For simple decisions:

```text
Expected Value
=
Σ Probability(outcome) × Value(outcome)
```

Example:

```text
Option A:
0.7 × 100 = 70

Option B:
0.4 × 180 = 72
```

On expected value alone, B is preferred in this simplified example.

But real decisions may also include:

- risk;
- reversibility;
- information value;
- time;
- moral constraints;
- worst-case outcomes.

---

# 6. Bayesian Updating

When new evidence arrives:

```text
Prior belief
     ↓
New evidence
     ↓
Updated belief
```

This can be compared structurally with the philosophical discipline of revising cognition when stronger evidence becomes available.

Do not equate Bayesian probability with classical *pramāṇa* theory.

---

# 7. Value of Information

Sometimes the best action is to gather more information first.

Ask:

> Would additional information materially change the decision?

If yes, investigate.

If no, further research may have little decision value.

---

# 8. Reversibility

Classify decisions:

```text
Reversible
Semi-reversible
Irreversible
```

The more irreversible the decision, the stronger the justification should generally be.

---

# 9. Decision Matrix

Use:

| Action | State 1 | State 2 | State 3 | Expected result | Main risk |
|---|---:|---:|---:|---:|---|
| A | | | | | |
| B | | | | | |
| C | | | | | |

This forces vague choices into explicit assumptions.

---

# 10. Nyāya-Inspired Decision Audit

Before acting, ask:

```text
What is the claim about the situation?
What evidence supports it?
What inference connects evidence to prediction?
What could defeat the inference?
What alternative explanation exists?
What is uncertain?
What action follows?
```

---

# 11. Common Decision Errors

Watch for:

- confirmation bias;
- sunk-cost reasoning;
- false certainty;
- availability bias;
- ignoring base rates;
- confusing possibility with probability;
- confusing confidence with evidence;
- ignoring opportunity cost;
- ignoring downside risk.

These modern labels can be compared with classical analyses of faulty cognition and reasoning, but they should not simply be translated into Sanskrit categories.

---

# 13. Decision Review

After the outcome, distinguish:

```text
Good decision + bad outcome
Bad decision + good outcome
Good decision + good outcome
Bad decision + bad outcome
```

Do not judge the quality of reasoning solely from the outcome.

---

# 14. Practical Project

Choose a real but non-sensitive decision.

Build:

1. decision matrix;
2. evidence list;
3. assumptions;
4. probability estimates;
5. expected outcomes;
6. downside analysis;
7. information-value analysis;
8. final decision;
9. post-decision review.

# Core Principle

> **A rational decision is not one guaranteed to succeed; it is one whose action is proportionate to the evidence, uncertainty, values, and consequences known at the time.**
