# Diagram & Conceptual-Map Resources

## Textual Sources for Building Diagrams

- [SARIT](https://sarit.indology.info/apps/sarit-pm/docs/welcome.html) — Searchable Indic texts useful for extracting concepts and relationships.
- [Sanskrit Library](https://www.sanskritlibrary.org/) — Sanskrit textual and terminology resources.
- [TITUS](https://titus.uni-frankfurt.de/texte/texte2.htm) — Textual and linguistic searching.

- Nyāya pramāṇas
- Nyāya five-membered inference
- Vyāpti / hetu / pakṣa / sādhya
- Hetvābhāsa
- Vāda / jalpa / vitaṇḍā
- Vaiśeṣika categories
- Mīmāṃsā pramāṇa theory
- Bhartṛhari's language theory
- Śabda / sphoṭa
- Buddhist pramāṇa theory
- Jain anekāntavāda / syādvāda
- Indian philosophical school relationships

These should be diagrams created from primary or carefully evaluated secondary sources rather than generic internet graphics.
