# Translation Resources

- [SARIT](https://sarit.indology.info/apps/sarit-pm/docs/welcome.html) — Indic editions downloadable as XML, EPUB and PDF.
- [Gītā Supersite](https://www.gitasupersite.iitk.ac.in/) — Texts with multiple commentary/translation resources.
- [SuttaCentral](https://suttacentral.net/) — Buddhist canonical texts with translations.
- [Sanskrit Library](https://www.sanskritlibrary.org/) — Sanskrit texts and analytical tools.
- [GRETIL](https://gretil.sub.uni-goettingen.de/gretil.html) — Machine-readable Indic text editions.

## Translation policy

Whenever possible preserve:

- Original-language text
- Transliteration
- Translation
- Translator
- Edition
- Commentary
- Date
- Source tradition
- Translation methodology

Never replace the original text merely because an English translation exists.
