# Cognition — Indian Philosophical Thoughts

> A structured personal research repository for studying Indian philosophy through epistemology, logic, inference, cognition, language, ontology, metaphysics, debate, and related forms of analytical thought — while connecting these ideas with problems of the modern world.

---

## About

**Cognition — Indian Philosophical Thoughts** is a personal study and research repository built around a collection of philosophical texts, reference materials, a structured curriculum, and practical modern applications.

The repository is designed around a simple principle:

> **Read carefully. Understand the system on its own terms. Reconstruct the argument. Compare only after understanding. Apply only without destroying the original distinctions.**

The collection has a strong emphasis on **Nyāya, Vaiśeṣika, Navya-Nyāya, Mīmāṃsā, and Bhartṛhari's philosophy of language**, with supporting material for epistemology, inference, cognition, ontology, metaphysics, language, debate, and reasoning.

This is **not intended to be a complete representation of Indian philosophy**. It is a focused research environment built around the resources currently collected.

---

# Objectives

The repository is intended to help develop the ability to:

- read difficult philosophical texts carefully;
- understand technical Sanskrit terminology in context;
- distinguish philosophical positions accurately;
- reconstruct arguments step by step;
- analyze inference and evidence;
- identify assumptions and counterexamples;
- understand debate and objections;
- compare different philosophical systems without collapsing their differences;
- investigate cognition, language, mind, ontology, and metaphysics;
- connect classical analytical methods with modern disciplines;
- conduct independent philosophical research.

The objective is **understanding and intellectual independence**, not merely completing a reading list.

# 3. `modern-applications/`

The philosophical material should not remain isolated from contemporary intellectual life.

This directory explores how analytical habits and philosophical questions can be brought into dialogue with modern fields.

It covers:

- **AI** — reasoning, memory, knowledge, hallucination, language, system architecture;
- **Cognitive Science** — perception, memory, cognition, error, self;
- **Critical Thinking** — evidence, assumptions, inference, counterexamples;
- **Decision Theory** — uncertainty, evidence, action, risk, value;
- **Law** — evidence, testimony, interpretation, argument;
- **Mathematics** — definitions, proof, formal reasoning, counterexamples;
- **Philosophy of Mind** — self, consciousness, cognition, agency;
- **Scientific Method** — observation, hypothesis, evidence, inference;
- **Software Engineering** — requirements, models, relations, debugging, testing, architecture.

These files deliberately distinguish **conceptual analogy from philosophical identity**.

For example:

```text
Anumāna
    ≠
Modern statistical inference

Manas
    ≠
Brain

Ātman
    ≠
Modern psychological self-model

Sphoṭa
    ≠
Modern computational representation
```

A comparison is useful only when its similarities **and limits** are made explicit.


# Reading Philosophy in This Repository

The recommended general workflow is:

```text
1. Locate the text
        ↓
2. Identify the school
        ↓
3. Clarify terminology
        ↓
4. Identify the philosophical problem
        ↓
5. Reconstruct the argument
        ↓
6. Identify objections
        ↓
7. Study the response
        ↓
8. Compare with another position
        ↓
9. Test the argument independently
        ↓
10. Apply the method to a modern problem
```

The order matters.

**Comparison before reconstruction often produces superficial equivalences.**

# Source Discipline

The books are the primary intellectual foundation of this repository.

When working on a philosophical question, distinguish:

```text
Primary text
    ↓
Commentary / translation
    ↓
Interpretation
    ↓
Comparison
    ↓
Modern analogy
    ↓
Personal hypothesis
```

These are not interchangeable.

A statement from a commentary should not automatically be presented as the author's original statement.

An AI-generated interpretation should never be presented as a quotation.

If exact textual support is unavailable, the uncertainty should be stated.

# What This Repository Is Not

This repository is **not** intended to be:

- a complete history of Indian philosophy;
- a replacement for the books;
- a claim that all Indian philosophical traditions agree;
- a claim that ancient concepts are identical to modern scientific concepts;
- a collection of isolated quotations;
- a system for memorizing Sanskrit terminology without understanding;
- an attempt to force every classical idea into modern categories.

It is a **structured personal research environment**.

# Intellectual Principles

### 1. Understand Before Evaluating

Do not criticize a position you have not reconstructed accurately.

### 2. Preserve Technical Distinctions

If two schools use similar words differently, preserve the difference.

### 3. Separate Evidence From Interpretation

Always know which layer you are working with.

### 4. Test Arguments

A philosophical claim should be examined through:

- premises;
- definitions;
- inference;
- assumptions;
- counterexamples;
- objections;
- replies.

### 5. Compare Carefully

Similarity is not identity.

### 6. Apply Without Anachronism

Modern applications are valuable only when the original philosophy remains intact.

### 7. Admit Uncertainty

A precise statement of uncertainty is better than false certainty.

### 8. Read Slowly Where Necessary

Dense philosophical texts often require rereading rather than simplification.

```text
       +
Logical analysis
       +
Epistemic discipline
       +
Argument reconstruction
       +
Comparative understanding
       +
```
